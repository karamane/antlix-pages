# Antlix — Support and privacy

Public support and privacy pages for Antlix, by ucansogan.

Support: ucansogan.games@gmail.com

## GitHub Pages

Push these files to the root of the `karamane/antlix-pages` repository. In Settings → Pages, select Deploy from a branch → main → /(root), then Save.

Expected home URL: https://karamane.github.io/antlix-pages/
Expected privacy URL: https://karamane.github.io/antlix-pages/privacy.html

These URLs become usable after deployment succeeds. Verify them in a signed-out browser before entering the privacy URL in Google Play Console.

## Scope

The privacy policy describes the offline Antlix test release without active advertising, real-money billing, analytics or cloud game saves. Review and update it before introducing services that change data practices. The website uses local styles and images, with no tracking scripts or external fonts.

English and Turkish content is included. Game source code and signing files are not part of this website.
